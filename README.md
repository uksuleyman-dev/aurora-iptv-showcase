# Aurora IPTV – Showcase

## Überblick
**Aurora IPTV** ist eine plattformübergreifende IPTV-Anwendung auf Basis von Flutter/Dart.

Die Anwendung integriert verschiedene externe Datenquellen und unterstützt Live-TV, Video-on-Demand, Serien, EPG, Timeshift, Recording sowie Multi-Screen- und Picture-in-Picture-Funktionen.

## Technischer Schwerpunkt
- Flutter / Dart
- Cross-Platform-Anwendungsentwicklung
- Integration externer APIs und Datenquellen
- Live-TV, VOD und Serien
- EPG, Timeshift und Recording
- Multi-Screen und Picture-in-Picture
- Automatisierte Build- und Release-Prozesse
- Separater Update-Kanal
- Produkt-, QA- und Architektur-Dokumentation
